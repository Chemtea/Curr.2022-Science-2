# 보호된 수업 자료 운영

수업·평가 HTML은 플랫폼의 자료 등록 기능으로 올립니다. GitHub의 차시 HTML은 로그인과 공개 상태를 확인하는 진입 파일이며, 편집용 원본이 아닙니다. 교사가 보유한 전체 HTML 원본으로 새 자료를 등록하거나 교체합니다. 원본과 4단계 정답 데이터는 서버의 비공개 테이블에 보관됩니다.

- 학생: 유효한 로그인, 현재 계정/학년도, 단원과 차시의 명시적 공개가 모두 필요합니다. 평가 자료에는 평가관 전체 공개 조건도 적용됩니다.
- 교사: 관리자 또는 교육과정 제어 권한이 있는 관리자는 잠긴 자료를 미리 볼 수 있습니다. 임시 교사용 관리자 모드도 지원합니다. 교사 미리보기에서는 학생 결과를 제출하지 않습니다.
- 형성평가: 4단계가 공개된 때 서버가 선택한 답을 판정하고 해당 피드백만 반환합니다. 공개 HTML에 정답표를 넣지 않습니다.
- 재잠금: 서버는 다음 요청을 거부하며 열린 화면은 실시간 알림 또는 주기적 검사로 차단됩니다. 이미 공개해 전달한 내용의 사본은 회수할 수 없습니다.
- 모범답안: 평가관의 별도 모범답안 항목을 열어 공개합니다. 기존 교사용 인쇄·수합 자료는 학생에게 제공하지 않습니다.

직접 GitHub에 전체 수업 HTML을 커밋하면 저장소 원본이 공개될 수 있습니다. 배포 검사가 이를 발견하면 Pages 배포를 중단하지만, 저장소 자체의 공개 범위는 별도 설정입니다. 과거 커밋·포크·캐시와 이미 내려받은 사본의 노출도 별도 처리 대상입니다.

## 서버 관리

`protected_lesson_assets`와 `protected_lesson_uploads`는 RLS 활성화 및 공개 클라이언트 권한 제거로 보호합니다. `lesson-content-api`가 기존 커스텀 세션을 검증한 뒤 자료를 제공하고, `lesson-upload-api`가 원본 저장 검증·Git 반영·본문 활성화를 순서대로 수행합니다. 등록 결과가 불확실하면 기존 등록 화면의 상태 확인으로 복구하며 새 원본을 공개 저장소에 직접 올리지 않습니다.

4단계 채점 응답 분리와 제출 결과의 서버 재채점은 별도 사항입니다. 이번 변경은 기존 제출·포인트 API 계약을 유지하며, 기존 클라이언트 계산 점수의 무결성까지 새로 보장하지 않습니다.
